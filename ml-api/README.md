# ML API components

Component-specific Python inference files are grouped in their own folders.

- `component-1-price/` — reserved for the Component 1 price ML API.
- `component-2-recommendation/` — reserved for the Component 2 recommendation ML API.
- `component-3-risk/` — active risk worker, recovered runtime, dependencies, and setup notes.
- `component-4-affordability/` — reserved for the Component 4 affordability ML API.
- `main.py` — generic expansion point for a future typed Python API.
